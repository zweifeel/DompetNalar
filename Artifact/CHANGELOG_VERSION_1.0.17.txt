BAGIAN A — CHANGELOG TEKNIS LENGKAP (AUDIT V16 -> V17)
--------------------------------------------------------------------------------

1. PEMENUHAN STANDAR KEBIJAKAN GOOGLE PLAY: TARGET SDK API LEVEL 36 (ANDROID 16)
   - Latar Belakang:
     Google Play Console mewajibkan target API level minimal 36 untuk seluruh pembaruan
     aplikasi baru guna memastikan keamanan, proteksi privasi, dan optimalisasi sistem operasi
     terbaru. Versi 1.0.16 sebelumnya menggunakan targetSdk 34 sehingga memicu penolakan
     unggah pada konsol.
   - Perubahan & Solusi:
     * Mengubah `targetSdk = 36` pada `app/build.gradle.kts`.
     * Mengatur `compileSdk = 36` untuk keselarasan modul API Android 16.
     * Menaikkan `versionCode` ke `17` dan `versionName` ke `"1.0.17"` untuk mencegah
       konflik artefak version code pada Play Console.
     * Mengaudit seluruh implementasi runtime permission, gesture navigation, dan lifecycle
       agar 100% kompatibel dengan arsitektur Android 16.

2. ELIMINASI TOTAL CRASH PEMILIHAN BAHASA (ANDROID 14 / REALME UI / COLOROS)
   - Menghapus mutasi OS paksa dari `LocaleHelper.kt` dan beralih ke arsitektur reaktif murni
     Jetpack Compose (`LocaleHelper.currentLanguage` StateFlow) tanpa *activity recreate*.
   - Proteksi Activity lifecycle pada `AndroidManifest.xml` (`configChanges`).

3. PERAPIAN LAYAR RIWAYAT TRANSAKSI / MUTASI & LOKALISASI KATEGORI
   - Perbaikan judul kartu ringkasan arus kas `"Cashflow Summary"` (EN) / `"Rekap Arus Kas"` (ID)
     sehingga tidak terpotong elipsis kaku.
   - Pelokalan nama kategori transaksi (contoh: "Shopping" pada mode English).

4. PEMBENAHAN TOMBOL PINTASAN TANGGAL & DYNAMIC DUE DATE (AI DEBT PLANNER)
   - Tombol pintasan tanggal tampil utuh dan proporsional:
     `[ Day 5 ]   [ Day 10 ]   [ Day 15 ]   [ Day 20 ]   [ End ]`.
   - Nilai awal *Due Date* otomatis menyesuaikan bahasa aktif ("Day 15 each month" / "Tgl 15 tiap bulan").
